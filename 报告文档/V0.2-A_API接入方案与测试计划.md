# V0.2 最小 API 接入方案与首次单篇实验测试计划

> 本文件仅为**方案与计划**。本阶段**未调用任何大模型 API、未使用任何密钥、未产生任何费用**，也**没有**用模拟输出冒充实验结果。
> 所有数字均来自本地脚本真实运行。

---

## 一、接入范围（刻意做小）

| 项目 | 决定 | 理由 |
|---|---|---|
| 服务商 | **1 家**，由你指定 | 多模型容易混淆结论归属，无法复现 |
| 模型 | **1 个**，由你指定 | 同上；首次实验只需验证"引用是否可信" |
| 接口形态 | OpenAI 兼容 `POST /chat/completions` | 国内主流服务商均兼容，无需额外 SDK |
| 输入 | 只传**本地存在、已核验、已去重、`quotable=true`** 的段落 | 从源头杜绝"读到不存在的政策" |
| 工具/联网 | **不给**任何工具、不给检索权限 | 模型只能读我们给的段落，无法自行补政策 |
| 输出 | 结构化 JSON（每条结论带 `para_ids` + `quotes`） | 便于程序机械核验，不依赖人眼审阅 |
| 存储 | 响应存本地 JSON 文件 | 不引入数据库、不引入向量库 |

**明确不做**：RAG、向量数据库、多轮对话、智能体编排、后端服务、用户权限、自动联网搜政策。

---

## 二、密钥与安全配置

### 2.1 密钥存放（唯一途径：环境变量）

```powershell
# 当前 PowerShell 会话内设置（关闭窗口即失效）
$env:LLM_API_KEY = "你的密钥"

# 或写入用户级环境变量，长期生效（需重开终端）
[Environment]::SetEnvironmentVariable("LLM_API_KEY","你的密钥","User")
```

**红线**：
- 密钥**不得**写入 `index.html`、任何 `.py`、任何 `.json`、任何 `.md`。
- `assistant_v02/api_config.json` **只放非敏感项**（服务商、地址、模型名、温度、上限），**不含密钥**。
- 脚本内置泄露扫描 `scan_for_leaked_key()`：若密钥明文出现在项目源码/网页/配置中，**直接报错并拒绝发送**。

### 2.2 配置文件（待你确认后填写）

`assistant_v02/api_config.json` 当前为：

```json
{ "provider": "", "base_url": "", "model": "", "endpoint": "/chat/completions",
  "temperature": 0.0, "max_output_tokens": 1200, "timeout_seconds": 120, "key_env": "LLM_API_KEY" }
```

需要你补充三项（示例形态，**不是推荐结论**）：

| 字段 | 需填内容 | 示例形态 |
|---|---|---|
| `provider` | 服务商标识 | `deepseek` / `openai` / 其他 |
| `base_url` | `https://` 开头的 API 根地址 | `https://api.example.com/v1` |
| `model` | 单一模型名 | 由你指定 |

### 2.3 三道闸门（防止误触发付费调用）

1. **默认 dry-run**：不加 `--send` 只打印请求摘要、段落数、token 估算，**不发包**。
2. **配置校验**：`provider/base_url/model` 任一为空、或 `base_url` 非 https → 拒绝发送。
3. **密钥扫描**：发现密钥明文落盘 → 拒绝发送。

## 三、调用流程（4 步，全部本地可验证）

```
① dry-run 预览       python assistant_v02/llm_client.py --file JS-004
        ↓  确认段落数/内容/成本无误
② 真实调用（需授权）  python assistant_v02/llm_client.py --file JS-004 --send
        ↓  响应落盘 assistant_v02/response_JS-004.json
③ 引用机械核验        python assistant_v02/verify_citations.py --file JS-004 --response response_JS-004.json
        ↓  citation_check.json
④ 人工抽检           对 grounded 结论回看段落原文
```

### 引用核验规则（`verify_citations.py`，已实现并通过逻辑自测）

| 判定 | 条件 | 处理 |
|---|---|---|
| ✓ grounded | `para_ids` 全部存在且可引用，且至少 1 个 `quote` 是该段落的**连续子串** | 计入有依据 |
| ✗ 编号不存在 | `para_ids` 含不存在的编号（如 `JS-004-P999`） | 标记无依据 |
| ✗ 编号不可引用 | 编号存在但 `quotable=false`（表格压平段） | 标记无依据 |
| ✗ 引用不落地 | `quote` 在该段落原文中查不到（逐字比对，去空白） | 标记无依据 |
| ✗ 空依据 | `para_ids` 或 `quotes` 为空 | 标记无依据 |

> 自测结果（`citation_check_selftest.json`，**人工构造样例，非模型输出**）：4 条样例中 1 条正确通过、3 条被准确拦截（编号不存在 / 无编号 / 引用不落地），校验器行为符合预期。

## 四、首次真实实验：单篇 · JS-004

### 4.1 唯一分析对象

| 项 | 值 |
|---|---|
| 文件编号 | `JS-004` |
| 标题 | 省教育厅关于印发《人工智能赋能教育高质量发展行动方案（2025—2027年）》的通知 |
| 官方原文 | https://jyt.jiangsu.gov.cn/art/2025/5/9/art_77619_11562404.html |
| 正文哈希 | `sha256:c6919a6e6c2c2ecba7a8f992718b497b2a7956dbb448d173f270e3e13736708a` |
| 传入段落 | **31 段**（全部 `quotable=true`，100% 可反向定位） |
| 输入 token | 约 **3569**（粗估，按中文字符/1.5 折算；实际以服务商计费为准） |
| 输出上限 | 1200 tokens |

> 只传 1 份文件、31 段，输入规模可控，便于逐条核验；**不生成长篇综述**。

### 4.2 要求模型输出的四类信息

1. **核心政策目标**（对应原文"（一）科学确立三年行动目标"等）
2. **主要实施措施**（对应"（三）～（二十二）"各项任务）
3. **关键时间节点**（2025 / 2027 等年份与对应任务）
4. **每条结论的 `para_ids` + 原文引用片段 `quotes`**

输出格式（强约束）：

```json
{"file_id":"JS-004","claims":[
  {"type":"目标|措施|时间节点","text":"一句话结论",
   "para_ids":["JS-004-P003"],"quotes":["原文中逐字出现的片段"]}
]}
```

### 4.3 通过标准（四条全满足才算通过）

1. 有依据结论占比 = **100%**（`grounded / total`）；
2. 无"编号不存在"类错误（说明模型没有编造段落号）；
3. 抽查 3 条 grounded 结论，其 `quote` 与 `para_ids` 指向的段落**逐字一致**；
4. 时间节点类结论全部能在原文中定位到年份/期限原句。

任一条不达标 → 视为实验失败，先修提示词或核验逻辑，**不进入 V0.3**。

### 4.4 成本控制

- 首次只跑 **1 次**单篇，不做多轮重试；如需重试，先记录上一次失败原因。
- 输入约 3.6k tokens、输出上限 1.2k tokens，规模极小。
- **具体单价由你确认服务商后按其官网价格核算**，本方案不预设价格。

## 五、需要你确认的事项（确认后我才发起真实调用）

1. **服务商 + 模型**（一家一个，写入 `api_config.json`）；
2. 是否已在环境变量设置 `LLM_API_KEY`；

在你明确确认之前，`llm_client.py` 始终保持 dry-run，**不会发出任何请求**。
