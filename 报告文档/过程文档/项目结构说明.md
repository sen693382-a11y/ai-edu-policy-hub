# 项目结构说明（阶段一）

## 1. 为什么这样分层

```
浏览器 ──HTTP──> api/fastapi_app.py 或 api/server.py
                      │
                      ▼
                api/router.py（框架无关分发）
                      │
        ┌─────────────┼──────────────┐
        ▼             ▼              ▼
  repositories/   services/       db/
  （所有 SQL）    （核验/种子）   （连接/迁移）
                                      │
                                      ▼
                              data/policy_hub.db
```

| 约束 | 落地方式 |
|---|---|
| 前端不承担网站抓取 | 采集模块属于阶段二 `backend/services/collector/`，阶段一未实现；前端仅通过 API 读数据 |
| 采集与数据管理独立模块 | `backend/repositories` + `backend/services`，API 层不含任何建表/抓取逻辑 |
| 数据库可迁移到 PostgreSQL | 所有时间戳由应用层写 ISO 8601 文本；不用 SQLite 专有 DEFAULT now()；SQL 走参数化查询；迁移按版本号分文件 |
| 附件可迁移到云端对象存储 | `attachment.local_path` 存相对路径，`storage/` 与数据库分离；未来只需替换存储适配器 |
| 断网可用 | `backend/db`、`repositories`、`services/seed.py`、`scripts/init_db.py`、`scripts/run_tests.py` 全部只用标准库 |
| 本地不暴露管理接口 | `serve.py` 拒绝非回环地址；默认 `127.0.0.1:8765` |

## 2. 目录职责

| 目录 | 职责 | 阶段一状态 |
|---|---|---|
| `backend/db/` | 连接、迁移执行器、4 个 SQL 迁移 | 已完成 |
| `backend/models/` | 数据模型说明（结构权威来源是 SQL 迁移） | 占位 |
| `backend/repositories/` | 全部 SQL 读写、字典校验、审核日志 | 已完成 |
| `backend/services/seed.py` | 地区 / 字典 / 标签 / 来源站点 / 覆盖状态种子 | 已完成 |
| `backend/services/verification.py` | P0 来源核验与状态流转 | 已完成 |
| `backend/api/` | 路由分发 + FastAPI / 标准库两种适配器 | 已完成 |
| `data/` | 配置 JSON + 生产 SQLite + 独立测试夹具 | 已完成 |
| `storage/attachments/` | 附件与备份 | 目录已建，空 |
| `scripts/` | 初始化、测试、启动、冒烟、备份、环境自检 | 已完成 |
| `tests/` | 49 项自动化用例 | 已完成 |
| `docs/` | 说明文档 + 机器生成的运行证据 | 已完成 |
| `frontend/` | React + TS + Vite + Tailwind 前端 | **阶段三，当前为空** |

## 3. 阶段一「不做什么」

- 不写任何正式政策 / 资料记录到生产库。
- 不做真实网页抓取（阶段二）。
- 不做前端页面（阶段三）。
- 不接大模型 API、不要 API Key。
- 不把用户提供的 3 条测试 URL 当作已核验来源。
- 不生成任何政策名称、发文字号、发文日期、正文或来源链接。

## 4. 未来扩展到在线网站需要改什么

| 项目 | 现在 | 上线时 |
|---|---|---|
| 数据库 | SQLite 单文件 | 换 `connection.py` 为 SQLAlchemy + PostgreSQL；迁移文件改写为 Alembic |
| 附件 | `storage/` 本地相对路径 | 对象存储适配器，保留 `original_url` 与 `content_hash` |
| 认证 | 无（仅本机） | 增加用户/角色、审核权限、操作审计 |
| 服务绑定 | `127.0.0.1` | 反向代理 + HTTPS + 访问控制 |
| 前端 | 无 | `frontend/` 静态构建，由后端托管或独立部署 |
| 采集 | 无 | `backend/services/collector/`，限速 / 退避 / 可恢复队列 |
