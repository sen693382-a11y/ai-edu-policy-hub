## 3. 已实现但有限制

| # | 限制 | 影响与缓解 |
|---|---|---|
| 15 | FTS5 `trigram` 索引对 <3 字中文词不生效 | 仓储层对 2 字及以下关键词用 `LIKE` 兜底，已有测试覆盖；长文本检索性能未做大数据量压测 |
| 16 | SQLite 单文件、单写并发 | 本地单人使用足够；多用户在线协作需迁 PostgreSQL |
| 17 | `source_check` 的自动内容比对当前由**核验服务接收外部传入的比对结果**，阶段一没有真实网页解析器 | 数据模型与约束已就位；阶段二接入真实抓取结果后才有端到端自动核验 |
| 18 | 备份只执行了 `--backup` 与 `--verify`，**未实际演练 `--restore` 恢复** | 恢复命令已实现（会先自动备份当前库），阶段四必须实战演练一次 |
| 19 | `setup.bat` / `start.bat` / `test.bat` 通过等价的 PowerShell 命令逐条验证，**未做双击 GUI 实机测试** | 阶段四补 Windows 双击启动流程验证 |
| 20 | `backend/models/` 为占位目录，结构权威来源是 SQL 迁移文件 | 不影响运行；若引入 ORM 需同步维护 |
| 21 | 三条官方站点可达性结果（HTTP 200）会随时间失效 | `docs/env_check.json` 记录了探测时间；阶段二重新探测 |

## 4. 阶段二开始前的确认点

1. 是否认可「生产库保持 0 条正式政策」作为阶段一交付基线（而不是先塞入示例数据）。
2. 是否授权按 PRD 的限速/退避规则实地访问用户提供的 3 条文章 URL 及其栏目，用于真实采集测试。
3. 是否接受浙江省文件在找不到原始发文机关页面时，只登记为「官方渠道全文发布/转载」，不补造原件链接。

> 阶段一没有调用任何付费 AI 服务、没有要求 API Key、没有生成任何政策事实。
