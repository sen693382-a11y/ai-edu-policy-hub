- **现状**：末段为 `（二十二）营造良好的人工智能教育及应用环境。…`（真实条款）

### 2. 删除 JS-001-P018 混入的政策解读关联文章标题

- **原状**：`《泰州市推进人工智能赋能教育高质量发展工作方案》解读`
- **处理**：同上规则
- **现状**：末段为 `各地各校要高度重视人工智能教育工作…`（真实保障条款）

### 3. 其他试点文件末尾的关联推荐/栏目导航

- 结果：**全库关联文章标题残留 0 条**（含 JS-003、ZJ-002、ZJ-004 等此前未点名的文件）

### 4. 政策日期 / 标题 / 正文混合连接

- **原状（ZJ-004-P003）**：`浙江省教育厅 浙江省发展和改革委员会浙江省科学技术厅 浙江省数据局2025年4月25日浙江省推进"人工智能+教育"行动方案（2025—2029年）为进一步深化人工智能在教育领域的创新应用…`
  —— 发文机关 + 日期 + 标题 + 正文首句挤在一段
- **处理**：`split_issuer_head()` + `strip_head_meta()` 三级剥离（机关+日期+标题 / 行首日期 / 行首重复标题），
  并在**行合并之后再做一次**（因为机关名被 `<br>` 拆成多行，需合并后才能识别）
- **现状**：`ZJ-004-P003` = `为进一步深化人工智能在教育领域的创新应用…`（纯正文）
- 机关/日期/标题作为**文档级元数据**保留，不再污染段落

### 5. ZJ-004-P009 按真实章节与编号条款重新分段

- **原状**：**3245 字**一段，含 `（一）～（五）` 全部章节 + `1.～16.` 全部条款
- **处理**：`split_units()` 三层切分——顶层章节 / `（N）` 章节 / `N.` 编号条款 / `（责任单位：…）` 括注后断句
- **现状**：拆为 **22 段**（5 个章节标题 + 16 个条款 + 1 段保障措施），例如
  - `ZJ-004-P009` = `（一）升级"人工智能+教育"基础环境`（18 字）
  - `ZJ-004-P010` = `1.建设教育大模型基础设施。…`
  - `ZJ-004-P018` = `（三）推进学生人工智能教育`
- 同一规则同步修复了 JS-004 / JS-001 / ZJ-002 的"章节标题与条款粘连"（如 `七、加强供给…（十六）夯实…`）

### 6. 绍兴市工作清单等附件：保留结构或明确标记

- **原状（ZJ-002 附件）**：`附件：绍兴市中小学人工智能教育工作清单（2025-2027年）…市人工智能教育科创中心建设人工智能孵化基地…`（表格被压成无分隔长串）
- **尝试还原失败的原因**：本地 HTML 的表格单元格已被压平，`序号/建设方向/项目/工作目标` 等列值散落，**无可靠分隔符**可循，强行还原等于**编造结构**
- **处理**：**不还原、不猜测**，保留原文文字并打上结构标记
  - `structure_note = "structure_loss:附件/清单原为表格，本地保存为无分隔纯文本，未能还原行列结构；已保留原文文字，未做推测性还原"`
  - `quotable = false`（**不得作为引用依据**），网页中以 `⚠不可引用` 红标展示

> 所有清洗只做**删除网页噪音**与**按结构切分**，未改动、未概括、未重写任何政策条款文字；条款编号连续性核验（见下）可佐证未被删减。
